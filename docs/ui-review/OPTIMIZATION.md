上表保留体积对比结果，原始统计快照仅保留在本地。剩余体积主要是 Electron 和固定 Codex 运行时，保留 code-mode host、ripgrep、zsh，避免损害执行、检索等能力。

审查方式：全仓文件/资产清单、依赖和构建入口、esbuild 完整依赖图、安装包所有文件、静态检查与全量测试；人工重点审查体积热点、平台配置及实际使用的桌面组件。没有声称逐行业务审计了所有代码，也没有把“搜索不到简单引用”当作删除动态模块的充分理由。

实际清理：

- 旧包重复包含约 179.48 MB 的 node_modules 文件：依赖源码、示例、重复发行格式等。主进程和 preload 已全部 bundle，renderer 已由 Vite 输出；现在安装包只带 package.json、dist 和明确的运行资源。
- 去掉安装包里的 `.map`；旧包各处调试映射总计约 87.61 MB（包含在上述重复体积中，不能相加计算收益）。生产构建先清理生成目录，避免混入开发构建遗留的 main.cjs.map。
- 主进程/preload 做语法与空白压缩，保留标识符可读性。增加构建检查：若出现 Electron/Node 内置模块之外的未 bundle 依赖，构建直接失败。
- 另行生成生产依赖第三方许可证汇总 `dist/THIRD-PARTY-LICENSES.txt`，保留现有产品、Router 与 Codex 授权声明。
- 删除六个已不再被 CSS 或模块引用的 OTF 字体，共 71,604,160 bytes。前轮已将字体偏好映射到系统字体，本轮未删除字体偏好选项或更改其既有行为。这主要减少源码体积；字体此前已不在 Vite 输出中，不冒称这部分缩小了 DMG。
- 移除 Windows 安装配置、Windows 发布任务及运行时下载清单，CI 使用 macOS；默认 `pnpm run dist` 只生成 macOS arm64 DMG，带 `--publish never`。打包前拒绝非 macOS arm64 目标。
- 保留少量跨平台条件与通用工具函数，因为它们不是安装体积来源，强删会扩大行为改动；没有删除任何模型、图片、流程图或论文能力。
- 删除不再需要的 Windows 运行时解包/下载缓存、Vite 缓存和五份旧解包应用，清理原有可生成文件 4.43 GB；另清理本轮中间解包副本。清理明细仅保留在本地。R1/R2 的 DMG、ZIP 和源码快照保留；未触及用户历史、配置或凭据。
- 删除 TopBar 约 80 行非必要布局动画及对应 CSS，保留导航、窗口控制事件和减少动画支持。

`packages/app` 经 `du -h` 从约 6.4 GiB 降至 3.2 GiB（仍含多个保留的历史安装包）。开发依赖保留以便继续构建测试；不要把整个源码目录当安装包交付。
